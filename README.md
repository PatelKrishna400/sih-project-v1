# Worker AI — Clean Minimal Industrial Assistant & Document Ingestion Platform

An ultra-clean, minimal, **100% Air-Gapped / Zero-Data-Leakage** AI assistant interface engineered for **factory floor workers, machine operators, and maintenance technicians**.

---

## Key Features

- **Clean Minimal Layout**:
  - No clutter or static text boxes in the main canvas.
  - Sidebar with Search History and **Worker Profile / Login**.
- **Centered Floating Search Bar**:
  - **`(+)` Attachment Menu**: Upload **Single Files** (`.pdf`, `.docx`, `.txt`), **Batch Manual Folders** (`webkitdirectory`), or **Intranet Wiki Links**.
  - **`🎤` Voice Input**: Speech-to-text voice recognition for hands-free queries.
  - **`⬆️` Instant Search**: Instant local resolution for machine error codes (e.g. *Siemens CNC Alarm 21612, Hydraulic LOTO, Motor VFD F0001, KUKA Collision*).
- **Interactive Action Checklists**:
  - Clear **Step 1 → Step 2 → Step 3** visual checklist cards.
  - **`🔊 Read Steps Aloud`**: Text-to-speech audio synthesis for listening through factory headphones.
  - **`Mark Completed`**: 1-click task signoff.
- **100% Client-Side & Air-Gapped**:
  - Zero external cloud dependencies or telemetry tracking — works standalone in any browser.
